# Neonküste – iPad-Spiel

Arcade-Fahrspiel von oben: Aufträge fahren, driften, der Polizei entkommen.
Eigenes Spiel (eigene Stadt, eigene Grafik), läuft komplett im Browser – kein Mac, kein App Store nötig.

| Datei | Zweck |
|---|---|
| `neonkueste.html` | Quelle (wird als Claude-Artifact veröffentlicht) |
| `index.html` | Eigenständige Version für jedes Webhosting (z. B. GitHub Pages) |
| `build.sh` | Erzeugt `index.html` aus `neonkueste.html` |

## Steuerung
- **iPad:** linker Daumen irgendwo hinlegen und in Fahrtrichtung ziehen. Rechts: Bremse, Drift, Nitro.
- **Tastatur:** Pfeile/WASD, Leertaste = Drift, Shift = Nitro, P = Pause.

## Aufs iPad
Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
